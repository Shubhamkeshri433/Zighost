# Zighost (working name, was MC Panel)

Local Minecraft server dashboard (Python backend, plain JS frontend, playit.gg for the public address).
Read `PLAN.md` first: it has decisions, architecture, phase status and open risks.

- The user writes in Hinglish (Hindi in Roman letters). Reply in the same style, short and plain.
- Backend is Starlette + uvicorn + psutil + requests. Do not add FastAPI/websockets unless asked.
- Frontend has no build step. `frontend/preview.html` is generated by `tools/make_preview.py`; do not edit it by hand.
- Run tests: `python -I tests/test_manager.py` (uses a fake Minecraft process, no Java needed).
- Update the checkboxes in PLAN.md when a feature is finished. Do not tick a box for code that is not on disk (this happened once).
- `frontend/demo.js` is the pretend backend for preview mode; keep its API shape in sync with `backend/app.py`.
- Preview without a backend: `python tools/make_preview.py`, then open `frontend/preview.html`.
- Version stays **0.1.0** until the user says otherwise. Never bump it.
- Work in saved stages: write to disk, run tests, add a log line to PLAN.md, then continue. Plan for the current round is PLAN.md section 10.
- Desktop-software rules (PLAN 10.6): no CDN or web fonts, pages never build file paths, all paths via `store.DATA`, `run.py` is the only entry point, remote calls go through the backend with cache and timeout.
- Reference screenshots live in `docs/refs/`: use the concept only, never copy the look.
- Name, version, publisher live only in `backend/brand.py` (page gets them from `/brand.js`). Never change `DATA_KEY` or `APP_ID`. Use `brand.NAME` / `BRAND.name`, never type the product name in code or text.
- Windows software plan is PLAN.md section 14: stages W0..W5, one at a time, wait for the user's "Go" before each. W0, W1 and W4 files (spec, installer/zighost.iss, tools/build_windows.py, .github/workflows/build.yml) are written; privacy/consent screen and Support dialog are already in (policy text in frontend/policy.js).
- Data folder: `ZIGHOST_DATA` env, else `%APPDATA%\zighost` in the packaged app, else `./data` for a source checkout. Logs in `<data>/logs`.
